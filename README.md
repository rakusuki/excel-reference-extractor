# excel-reference-extractor

自然言語の報告文から、Excel のシート名と行番号を検出し、Excel 参照形式へ変換してクリップボードへコピーする Chrome ブックマークレットです。

たとえば、次のような文章を入力します。

```text
田中さんシートの 788 に記載済み
```

次の形式へ変換します。

```text
田中!A788:C788
```

## 主な機能

- 登録済みのシート名を自然言語の文章から検出
- 全角数字を半角数字へ正規化
- 「行」「行目」が付いた行番号を抽出
- シート名直後であれば、「行」を省略した数字も行番号として抽出
- 括弧付きの行番号に対応
- 複数行、連続範囲に対応
- 隣接する行番号・範囲をまとめて Excel の範囲参照へ変換
- 結果をクリップボードへコピー
- Clipboard API が利用できない場合は、コピー用ダイアログを表示

## 対応例

| 入力 | 出力 |
| --- | --- |
| `田中さんシートの 788 に記載済み` | `田中!A788:C788` |
| `田中さんシート 788 に記載済み` | `田中!A788:C788` |
| `田中さんシートの788に記載済み` | `田中!A788:C788` |
| `田中さんのシートの 788 に記載済み` | `田中!A788:C788` |
| `田中さんの[322]行目に記入いたしました` | `田中!A322:C322` |
| `田中さん319行目` | `田中!A319:C319` |
| `田中さん319、320行目` | `田中!A319:C320` |
| `田中さん319〜322行目` | `田中!A319:C322` |

## 使い方

1. `bookmarklet.js` を開き、内容をすべてコピーします。
2. Chrome で新しいブックマークを作成します。
3. ブックマークの URL 欄へ、コピーした内容をそのまま貼り付けます。
4. 任意のWebページで登録したブックマークを実行します。
5. 表示された入力欄へ報告文を貼り付けます。
6. 抽出された Excel 参照先がクリップボードへコピーされます。

`bookmarklet.js` の先頭には `javascript:` が含まれているため、URL欄では削除せずそのまま登録してください。

## シート名の設定

ブックマークレット冒頭の `S` に、検出対象のシート名を登録します。

```javascript
const S = ["田中", "佐藤", "鈴木", "営業 田中"];
```

実際に利用する Excel ファイルのシート名に合わせて変更してください。

長い名前と短い名前が重複する場合に備え、内部では文字数の長いシート名から優先して照合します。

## 出力列の設定

現在は、抽出した行番号を A 列から C 列までの範囲として出力します。

```javascript
SC = "A";
EC = "C";
```

たとえば 788 行目を検出した場合は、次のようになります。

```text
田中!A788:C788
```

開始列・終了列を変更したい場合は、`SC` と `EC` を変更してください。

## 対応する行番号表現

### 単一行

```text
319行
319行目
```

### 範囲

```text
319～322行目
319-322行
319から322行
```

### 複数行

```text
319、320行目
319,320行目
319と320行目
319及び320行目
319および320行目
```

連続している行は、自動的にひとつの範囲へまとめます。

```text
319、320行目
```

↓

```text
A319:C320
```

### 括弧付き

次のような数字も認識します。

```text
[322]
［322］
【322】
(322)
（322）
```

### 「行」が省略された数字

シート名の直後にある数字については、「行」「行目」が省略されていても行番号として扱います。

```text
田中さんシートの 788 に記載済み
```

↓

```text
田中!A788:C788
```

この判定は誤検出を抑えるため、文章中にある任意の数字ではなく、シート名直後の数字だけを対象にしています。

たとえば、

```text
田中さんシートについて確認しました。2026年9月30日に対応しました。
```

の `2026` は、行番号として扱いません。

## シート名の出力

英数字・日本語・アンダースコアのみで構成されるシート名は、そのまま出力します。

空白などを含むシート名は Excel の参照形式に合わせてシングルクォートで囲みます。

```text
営業 田中
```

↓

```text
'営業 田中'!A788:C788
```

シート名内にシングルクォートが含まれる場合も、Excel の形式に合わせてエスケープします。

## 複数のシート名がある場合

1つの文章に複数の登録済みシート名が含まれる場合、それぞれのシート名から次のシート名までを解析対象として行番号を抽出します。

複数の参照先が得られた場合は、読点 `、` で連結して出力します。

## 制約

- シート名はあらかじめ `S` に登録する必要があります。
- 現在の列範囲は `A:C` 固定設定です。必要に応じて `SC` / `EC` を変更してください。
- 「行」が省略された数字は、シート名直後にあり、かつ後続文字が `に`、`へ`、`を`、`で`、句読点など特定形式の場合のみ認識します。
- ブックマークレットは入力文の意味をAIで解析しているわけではなく、定義済みの正規表現ルールに基づいて抽出します。
- Webページの Content Security Policy やブラウザ設定によっては Clipboard API が利用できない場合があります。その場合はコピー用ダイアログへフォールバックします。
